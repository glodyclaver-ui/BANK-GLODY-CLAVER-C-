# BANK-GLODY-CLAVER-C-
Le programme est un simulateur bancaire premium couplé à un courtier boursier  (Broker) mondialisé à haute fréquence. Il simule des flux de compensation et  des comptes localisés dans 5 puissances ou zones géographiques distinctes :  la RDC, la France (Zone Euro), le Canada, la Chine et le Royaume-Uni.
